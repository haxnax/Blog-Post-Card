# Blog Post Card
<img width="435" height="579" alt="image" src="https://github.com/user-attachments/assets/417d8341-b801-41bb-a52e-eeaa98216def" />

A clean, responsive blog post card built with plain HTML and CSS. The page shows a featured image, a short post title, a summary, and a call-to-action button.

## Preview

Open `index.html` in a browser to view the card.

## Features

- Simple static layout with no JavaScript required
- Centered card with rounded corners and shadow
- Responsive image and readable content spacing
- Easy-to-edit text and styling

## Project Structure

- `index.html` - page markup and content
- `css/styles.css` - card styling and layout
- `images/` - optional folder for local assets

## How to Run

1. Open the project folder in VS Code or your file explorer.
2. Open `index.html` in a browser.
3. Edit the content and styles as needed.

## Customization

- Change the title, excerpt, and link text in `index.html`.
- Replace the image source with a local file if you want to use your own artwork.
- Adjust colors, spacing, and typography in `css/styles.css`.

## Notes

- The current image is loaded from an external URL.
